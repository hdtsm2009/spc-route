## A. 新機能チェック（機能別）

### A-1. 本命度（勢いスコア）と並び順
1. トップで「新宿」チップ→「🔍 候補を検索」。
2. STEP2の候補リストを上から見る。
- [ ] 各カードに **本命度ラベル**（例：`本命度: 本命◎(無料→有料)` `最優先` `奪取狙い`）が出る
- [ ] **勢いチップ**（例：`🔥★4.5・口2.3k・¥¥`）が出る店がある（評価・口コミ・価格帯）
- [ ] 並びが **ランク（S→AS→AF→B→C）→ 勢いの強い順** になっている（AS同士は勢いスコア高が上）
- **研修ポイント**：AS＝スポカフェ無料掲載＝有料転換の本命。その中でも**勢いチップが付いた人気店から攻める**のが基本。

### A-2. 候補の地図プレビュー
1. STEP2のタブ「🗺 地図で見る」を押す。
- [ ] 地図が表示され、**ピンの色でランク**が分かる（凡例：S赤／AS橙／AF／B青／C灰、⭐＝起点）
- [ ] **ピンが密集すると丸い数字（クラスタ）にまとまる**／拡大すると個別ピンに分かれる
- [ ] 店を選ぶと**ピンに番号①②③**が付き、起点から**近い順に緑の点線**でつながる（周遊イメージ）
- [ ] ピンをタップ⇔リストのカード選択が**連動**する
- [ ] 「📋 リスト」タブに戻せる（既定はリスト）
- **研修ポイント**：地図は「選んだ店が1日で回れる固まりか」を確かめる用途。線は距離の目安（実際の道順は発行するGoogleマップで）。

### A-3. 選択サマリー
1. 候補をいくつかチェックする。
- [ ] リスト下に **「選択◯件（本命S/AS ◯件）・推定周遊 約◯分・総移動 約◯km」** が出る
- [ ] 店を増減すると数値が**即更新**される
- **研修ポイント**：推定周遊時間で「**詰め込みすぎ・遠すぎ**」を防ぐ。本命数も一緒に見て質を担保。

### A-4. 絞り込みフィルター／エリアチップ
- [ ] エリアチップが **首都圏／関西／その他** に分かれている
- [ ] 絞り込み：**徒歩5/10/15分以内**・**🟢営業中のみ**・**チェーン除く**・**未接触のみ** が効く
- [ ] 並び替え「本命度順／近い順」が効く、ランク（S/AS/AF/B/C）チップのON/OFFが効く
- **研修ポイント**：「**徒歩10分以内＋営業中＋未接触**」で絞ると、その場で回れる本命だけが残る。

### A-5. 訪問結果の記録・接触履歴（チーム共有）★重点
1. 任意の候補カードの「**＋訪問結果を記録**」から「訪問済」等を選ぶ（担当者はSTEP1の担当者が使われる）。
- [ ] カードの表示が **「🟣 ◯◯が◯月◯日に「訪問済」」** に変わる
2. もう一度同じエリアを検索し直す／別端末で開く。
- [ ] 記録した店に**接触履歴バッジが残っている**（＝チームで共有されている）
- [ ] 記録していない店は **「未接触」** と出る
- [ ] 「未接触のみ」フィルタで**訪問済みが消える**
3. 記録を「＋訪問結果を記録」で空（未記録）に戻すと履歴が消える。
- **研修ポイント**：**訪問したらその場で記録**する運用を徹底すると、チームの二重訪問が無くなる。まだ実データは空なので、研修で「記録する習慣」を作るのが肝。

### A-6. 閉店店の自動除外
- [ ] 候補リスト・地図に **「閉店」「除外」表示の店が出ていない**（閉店・移転が確認された店は自動で出ない）
- **研修ポイント**：地図情報で閉店確認済みの店は除外済み。ただし**現地で看板が変わっている**こともあるので、重要店は訪問前に電話確認を。

### A-7. 掲載店データの刷新（番地住所・新規掲載店）
1. 候補カードの住所を数件見る。
- [ ] スポカフェ掲載店の住所が **番地まで入っている**（例「東京都渋谷区宇田川町3-10…」）
- [ ] 地図ピンが**住所と合った位置**にある（以前のような大きくズレた誤りが無い）
- **研修ポイント**：掲載店データは公式の最新版に更新済み。**新しい掲載店も候補に出る**ようになった。

### A-8. 更新履歴の表示
- [ ] トップに「🆕 更新履歴（大きめの改善）」があり、**直近3件が常時表示**・それ以前は折りたたみ
- **研修ポイント**：機能追加はここで周知される。研修時の「最近の変更」確認に使える。

## 補足：ランクの早見表
| ランク | 意味 | 営業の狙い |
|---|---|---|
| **S** | スポカフェ＋ファンスタ両方掲載 | 最優先 |
| **AS** | スポカフェのみ掲載（多くは無料） | **本命**＝無料→有料転換／上位アップセル |
| **AF** | ファンスタのみ掲載 | 競合から奪取 |
| **B / C** | 未掲載 | 新規開拓（B=有望 / C=温度低め） |

並び順は **S→AS→AF→B→C**、同ランク内は**勢いスコア→近い順**。
仕組みの詳細は本番ページの「▶ 仕組み・店舗選定基準」リンク（/guide.html）も参照。
