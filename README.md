# 訪問店舗提案サービス

アポイント（固定点）の前後の空き時間に、近隣の**営業ターゲット店舗**を
移動効率の良いルートで回るプランを自動提案するための社内ツール。

> 例：「西日暮里に19:00アポ。17:00〜22:00の枠で、ついでに回るべき店とルートを提案して」

---

### AS店（スポカフェ掲載店）の勢いエンリッチ・閉店検証パイプライン

スポカフェ掲載店は番地・評価・口コミがマスタにほぼ無いため、Google Placesで補完する（要APIキー・従量課金）。

```powershell
# ① AS店の評価/口コミ/価格/営業状況を取得（--all で全件、--limit N でテスト）
python _scripts/フェーズ04d_AS勢いエンリッチ.py --all

# ② 閉店候補の多段検証 L1(同名同市)+L2(Place Details)
python _scripts/スポカフェ閉店検証_L1L2.py
#   重要店はWeb独立確認(L3)し _data/l3_verdicts.json に手動記録

# ③ 誤検出店の再ジオコーディング（店名一致を必須にして座標を取り直す）
python _scripts/フェーズ04e_誤検出再ジオコーディング.py

# ④ 統合（フェーズ06）→ JSONエクスポート
python _scripts/フェーズ06_AS勢い統合と閉店除外.py
python _scripts/マスタJSONエクスポート.py

# スポカフェ管理マスタ向け「閉店済み／所在不明」納品データ生成
python _scripts/スポカフェ閉店済みリスト生成.py
```

**実行順序（旧・POI経路。2026-06-02に正攻法へ移行済）**：統合マスタ構築 → … → 04c(POI座標) → 06 → エクスポート

## 訪問プラン生成（日常利用）

```powershell
# 対話モード（推奨）
python _scripts/ルートプラン生成.py

# 引数指定モード
python _scripts/ルートプラン生成.py ^
  --appt_name "○○バー" ^
  --appt_addr "東京都荒川区西日暮里5-9-5" ^
  --appt_start 19:00 --appt_end 20:00 ^
  --window_start 17:00 --window_end 22:00 ^
  --owner 鈴村 --max 5
```

出力: `_output/route_plans/訪問プラン_〇〇_日時.html`
→ ブラウザで開き、営業メモを入力して印刷（Ctrl+P）

## 設定変更

`_config/設定.json` を編集してパラメータを調整できます。

| 項目 | 設定キー |
|---|---|
| チームメンバー一覧 | `team.members` |
| 検索半径(m) | `route.search_radius_m` |
| 1店舗あたり滞在時間(分) | `route.stay_minutes_per_store` |
| アポ前バッファ(分) | `route.buffer_before_appt_min` |
| スコア重みづけ | `scoring.base` / `scoring.penalty` |
| S/A/B/C閾値 | `scoring.thresholds` |
